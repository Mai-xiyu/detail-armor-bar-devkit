# 自动识别与 unknown 回退

细节盔甲 HUD 提供两个面向玩家的兼容设置：

- 自动识别模组盔甲贴图
- 未知盔甲回退图标

两个选项默认开启。

## 自动识别开启

开启后，HUD 会尝试读取物品基础信息和物品贴图路径：

- 使用物品基础信息中的护甲值
- 根据物品名推断 `materialKey`
- 使用物品 UI 图标作为 HUD 图标缓存

这适合大多数按标准方式声明的自定义盔甲。

## 自动识别关闭

关闭后，不再尝试解析自定义盔甲贴图。

如果 unknown 回退开启，未知自定义盔甲会统一显示 `unknown_armor` 图标。

如果 unknown 回退关闭，无法解析的自定义盔甲不会显示。

## 开发者配置优先

无论玩家设置如何，开发者显式配置始终优先。

这可以保证特殊盔甲、非标准槽位命名、特殊图标路径等场景仍然可控。

## 推荐策略

- 标准盔甲：优先依赖自动识别
- 有特殊显示需求的盔甲：提供开发者配置
- 不确定材质来源的盔甲：允许 unknown 回退
- 对 HUD 视觉一致性要求高的整合包：建议关闭 unknown，只保留显式适配
