# HUD 图标贴图规范

本文说明自定义盔甲 HUD 图标的推荐制作方式。

## 推荐尺寸

- 推荐使用 `16x16`
- 可以使用等比例尺寸，但最终显示应能清晰缩放到 16x16
- 图标背景应透明

## 路径规范

推荐把图标放在资源包内：

```text
textures/ui/detail_armor/
```

示例：

```text
textures/ui/detail_armor/ruby_armor
```

配置中通常不需要写 `.png` 后缀，具体以项目资源加载方式为准。

## 半格显示

细节盔甲 HUD 会根据护甲点拆分左右半格：

- 左半格附魔时，仅左侧显示光效
- 右半格附魔时，仅右侧显示光效
- 左右同材质时，底图合并为完整图标
- 左右不同材质时，底图按半格分别裁切

因此贴图应尽量保持左右两半视觉连续，避免中线附近出现明显断裂。

## unknown 图标

`resources/textures/ui/detail_armor/unknown_armor.png` 是未知盔甲回退图标。

建议仅在以下场景显示：

- 自动识别关闭
- 物品是盔甲，但没有可用材质图标
- 开发者未提供显式适配

如果 unknown 回退也关闭，无法解析的盔甲不应显示在 HUD 中。
